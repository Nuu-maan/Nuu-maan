### Selected projects

* [`coffer`](https://github.com/Nuu-maan/coffer)
  A capture buffer and prompt queue for AI-assisted work, for Windows and Linux. Collect errors, snippets and context while you work, then hand them to your assistant together.

* [`undertone`](https://github.com/Nuu-maan/undertone)
  A text box that tells you how your message sounds before you send it: passive-aggressive, over-apologizing, not boss-safe. Live at [undertone-app.vercel.app](https://undertone-app.vercel.app).

* [`pastewise`](https://github.com/Nuu-maan/pastewise)
  Paste anything, get the right tool. Recognises JSON, JWTs, cron expressions, stack traces and more, and turns into the tool for each. Live at [pastewise.vercel.app](https://pastewise.vercel.app).

* [`ttysvg`](https://github.com/Nuu-maan/ttysvg)
  Record your terminal, get one self-contained animated SVG for your README. Real, selectable text and light and dark palettes in a single file. Written in Rust, works on Windows.

* [`oubliette`](https://github.com/Nuu-maan/oubliette)
  Discord server repurposed as an encrypted Windows drive. AES-256-GCM per-chunk encryption, SHA-256 integrity, sharded across channels, mountable as `Z:\` via WinFSP. Educational Rust project covering distributed storage, async runtimes, and end-to-end systems engineering.

* [`pinterest-mcp`](https://github.com/Nuu-maan/pinterest-mcp)
  MCP server that lets Claude or any MCP client search Pinterest and download full-resolution images and boards.

* [`video-streaming-service`](https://github.com/Nuu-maan/video-streaming-service)
  Professional video streaming backend with Go, HLS adaptive bitrate streaming, transcoding, and Redis caching. Ready for deployment.

* [`FastAPI Authentication Boilerplate`](https://github.com/Nuu-maan/FastAPI-Authentication-Boilerplate)
  Production-ready authentication starter for FastAPI with clean architecture, JWT (access/refresh via HttpOnly cookies), email verification, password reset, RBAC, sessions, and auditing.

* [`flappyfly`](https://github.com/Nuu-maan/flappyfly)
  The complete male *Drosophila* connectome, simulated as a spiking network, evolving to play Flappy Bird. The brain is never trained; only a linear readout on top of its activity learns.
