### Selected projects

#### [`oubliette`](https://github.com/Nuu-maan/oubliette) &nbsp;·&nbsp; `Rust · WinFSP · AES-256-GCM`
A Discord server repurposed as an encrypted Windows drive. Files get chunked, AES-256-GCM encrypted, SHA-256 verified, hash-sharded across channels, and mounted as `Z:\` via WinFSP. Built as an educational project covering distributed storage, async runtimes, FUSE-style filesystems, and end-to-end systems engineering in Rust.

#### [`chat-api`](https://github.com/Nuu-maan/chat-api) &nbsp;·&nbsp; `Python · WebSocket · Postgres`
Real-time WebSocket chat API with persistent messaging support.

#### [`FastAPI Authentication Boilerplate`](https://github.com/Nuu-maan/FastAPI-Authentication-Boilerplate) &nbsp;·&nbsp; `FastAPI · JWT · RBAC · Postgres`
Production-ready authentication starter with clean architecture, JWT (access / refresh via HttpOnly cookies), email verification, password reset, role-based access control, sessions, and auditing.

#### [`Filly-Discord-Token-Filler`](https://github.com/Nuu-maan/Filly-Discord-Token-Filler) &nbsp;·&nbsp; `Python · automation`
Automates Discord server joins using multiple tokens. Scripted, parallel, efficient.

#### [`ZeroShare`](https://github.com/Nuu-maan/ZeroShare) &nbsp;·&nbsp; `WebCrypto · E2EE · privacy`
End-to-end encrypted file drop system — like Firefox Send. The server never sees your files or keys; only the person with the link can decrypt.

#### [`video-streaming-service`](https://github.com/Nuu-maan/video-streaming-service) &nbsp;·&nbsp; `Go · HLS · ffmpeg · Redis`
Production-grade video streaming backend with HLS adaptive bitrate, transcoding, and Redis caching. Deployment-ready.

#### [`DSA`](https://github.com/Nuu-maan/DSA) &nbsp;·&nbsp; `Python · JavaScript · C++`
Organized DSA practice repo with real interview questions and clean solutions across three languages, structured by topic and difficulty.
